## 数值模型的具体限制

`belief/baseline.py` 排除所有 stale 锚点；`config/settings.yaml` 将 stale_days 设置为 180。
`belief/scenario_updater.py` 的时间跨度为 target_date - as_of，而不是从历史锚点日期开始；代理额外误差是固定值，没有随锚点年龄变化。
因此，把一个旧融资金额直接放过时效筛选，仍不足以正确表达其陈旧性。改进应同时处理锚点日期、时间传播、事件计价和不确定性，并披露假设。

任务书允许启发式参数和融资代理，也允许不足时拒绝；拒绝本身符合规范，但不能据此宣布真实结果验收完成。

## 不应计为 V1 未实现的项目

- 概率校准、滚动回测、训练、大型因果模型、多智能体系统、交易：属于 V2 或明确排除范围。
- Polymarket 官方 API 与合约复现：按最新用户澄清，均不作为本项目验收前提。
- NPM/Forge 专用数据权限：选择其结算口径时才需要，融资代理路线已由 prompt 允许。
- DeepSeek 真实调用验收：目前千问已实测，DeepSeek 仅兼容接口；切回 DeepSeek 时才需该服务密钥。
- API 中途精确续跑：尚未实现，但不等于用户要求的开发记录续接未完成；AGENTS/PROGRESS 已保存续接说明。
- 实际账单：当前记录供应商 token 与预算估计，任务书允许预算估计；不应伪称账单金额。

## 用户需要提供的内容

1. 不再需要 Polymarket 合约链接。若用户有偏好的私募报价平台，可指定；否则开发者可继续研究公开来源。
2. 若有非公开的近期已完成融资/股权交易资料或 NPM/Forge 报价，提供合法可用来源、日期、单位、指标口径；这是可选加速项，不是把研发责任转给用户。
3. 若没有这些材料，仍可以按 prompt 已允许的融资代理路线推进代码改进与公开来源核实，无需再次索取 Tavily/千问密钥或 GPU。

优先级：锚点时间模型 → 证据时间与研究覆盖检查 → 完整真实概率报告 → 任务解析/语义检索/历史解释完善。
