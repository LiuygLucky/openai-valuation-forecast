# V1.4 信念更新修订与离线对照

## 问题

已存档的 `3b5d47809dbb4830821e8fc36989a05f`（模型 v1.3）中，所有事件 `log_shift=0`，更新分布与锚点基准逐项相同。这不是 UI 错误：现有证据全部在最新 NPM 锚点之前公开，旧算法为避免重复计价，将它们全部排除在事件调整之外。它因此未利用“过去已公开、但未来结果尚未实现”的预测信息来刻画终点风险。

## 新规则

信念更新现在区分两种作用：

1. **锚点后的新披露**：有被接受的证据、非中性因果机制和有效日期时，仍按现有 `log_shift` 规则调整。该路径在离线 DEMO 中已有非零事件调整测试。
2. **锚点前已公开的未来预测**：不当作新的价格冲击。只有证据 `claim_kind=forecast`、引句包含目标年份、属于非估值/融资类别、被审查接受、且关联方向一致的因果假设时，加入一个**零均值的未来兑现风险**。每条风险采用 `{-a, 0, +a}`，权重 `{0.25, 0.5, 0.25}`，其中 `a=event_log_shift`，默认 0.025。它表达未来实际结果可能比当前报价隐含预期好或差；不声称知道市场已计入的具体数值或方向性惊喜。

```text
基准终点样本 = NPM 锚点 × exp(漂移 + 波动噪声)
更新终点样本 = 基准终点样本 × exp(锚点后事件调整 × 情景倍率
                                  + 已公开未来预测的零均值兑现偏差)
```

新增 `future_realization_risks` 保存参与更新的事件 ID、证据 ID、方向和幅度；`scenario_assumptions` 保存离散结果与权重。报告表增加每个区间相对锚点基准的百分点差异。模型版本为 v1.4；v1.3 及更早历史记录仍调用原数值规则，归档报告保持原样。

## 不联网离线对照

输入是上述已存档 LIVE 的 `state.json`，不重新搜索、不调用 LLM，也不覆盖原报告。运行：

```powershell
.\.venv\Scripts\python scripts\compare_belief_update.py reports\runs\live\3b5d47809dbb4830821e8fc36989a05f\state.json --output reports\analysis\belief_update_v14_counterfactual.json
```

该状态中，审查接受了路透社转载的“OpenAI 预计 2026–2030 年现金消耗”陈述，`claim_kind=forecast`，相关因果假设方向为负。v1.4 将其作为未来兑现风险。其他锚点前已发生融资、客户和收入陈述未被再次当作新冲击。保存的对照文件显示：`750–1000B` 从 11.930% 变为 12.056%（+0.126 个百分点），`1250–1500B` 从 32.042% 变为 31.934%（−0.108 个百分点）；其余区间差异也逐项保存。中位数从 1262.393 变为 1262.323 USD billion。移除这条预测证据后，新旧基准分布相同，回归测试验证了此消融结果。

另有受控测试构造一条锚点后才公开、且有正向因果机制的新收入事实，验证方向性 `log_shift>0` 且概率分布变化。它是合成测试条件，不代表现实中已发生了该事件。

这只是**算法反事实对照**，不是 2026-11-04 新的 LIVE 预测。已存档的 v1.3 数值核验仍通过。新规则仅证明认知证据可以在明确条件下改变计算分布，尚未证明改变方向、幅度或概率更接近未来实际估值。由于样本数为 50,000，极小的百分点差异还包含蒙特卡洛抽样误差。

## 仍需解决

- `a=0.025` 与 0.25/0.5/0.25 权重是研究者设定，未根据 NPM 历史数据估计。
- 已公开预测相对于市场隐含预期的真正偏差未知；因此新规则不施加无依据的单向平均漂移。
- 当前只有粗粒度的年份检查，不能准确拆分跨年度预测中已实现与未实现的部分。
- 要证明预测质量改善，需收集按当时可得信息构建的历史快照、目标日真实结算值，设计滚动回测和消融比较，再用 Brier score、校准曲线等评价。不能用今天可见的旧新闻冒充过去某日已可获得的资料。
